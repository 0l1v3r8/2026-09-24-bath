Setup

All the activities in this workshop will be done using Noteable, a cloud-based platform that provides access to Jupyter Python notebooks, terminals, and other tools. You do not need to install any software on your own computer to take part in the workshop.

You can find the link to the Noteable platform and your workshop materials on the workshop's Moodle page. Once you have logged in, select the "Standard Python 3" personal notebook server option and click "Start".

Download the file swc-samba-cdt.zip from the workshop's Moodle page, then upload it to your Noteable workspace by clicking the "Upload" button in the top right corner of the Noteable interface and selecting the file.

Next, open a terminal in Noteable and unzip the file using the command: 

unzip swc-samba-cdt.zip

Note: if you are prompted to replace .DS_Store, you can safely type "n" and press Enter to skip it.

Your Noteable server is temporary. Everything in your workspace is deleted when the server is shut down or your session ends. Before you finish each session, download any files you want to keep (right-click a file in the JupyterLab file browser and choose "Download"). At the start of the next session, you will need to re-upload the workshop data to Noteable again before you can continue.

Once the zip file has been extracted, the JupyterLab file browser on the left should show the following at the root of your workspace:

  • shell-lesson-data/
  • python-lesson-data/
  • shared-data-Oth_MPG_SoftwareSkills/
  • instructor-courses/
  • swc-samba-cdt.zip

If you do not see these folders, check that the zip file was extracted successfully and try unzipping it again.
